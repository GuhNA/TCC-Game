# Hero Walk V3 — revisão

Arquivo: HERO_WALK_36F_v3.png, 1956 × 1806 pixels, RGBA.
Slice: Grid by Cell Size, 326 × 301, offset/padding zero.
Pivot Custom: X=0.5, Y=0.053156146. PPU=100; Point; sem compressão ou mipmaps.

Ordem da esquerda para direita: linhas 1–2 UP, 3–4 DOWN, 5–6 RIGHT.
12 quadros por direção, 11 FPS, loop. GIFs aproximam o tempo para 90 ms/quadro.

RIGHT parte da candidata aceita, com movimento adicional na capa. UP/DOWN são novas versões para revisão, com poses de pernas ainda repetitivas; não estão certificadas como caminhada natural. Conferência estática: sem pixels nas bordas das células. O alinhamento técnico usa eixo da cabeça e base da bota, não uma garantia de estabilidade anatômica entre desenhos.

Os originais e o controlador do jogador não foram substituídos. O instalador Editor cria apenas sprites, três clips, controller e prefab de revisão em HeroWalkCapeV3. A geração usou a ferramenta de imagem integrada; a montagem da grade foi determinística, sem redesenho por script. Não há teste visual desta versão no Animator confirmado nesta entrega.
